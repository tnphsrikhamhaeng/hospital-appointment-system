## 2. Layer Responsibility

ระบบแบ่งหน้าที่ของแต่ละ Layer อย่างชัดเจน ตามหลัก Separation of Concerns เพื่อให้แต่ละส่วนรับผิดชอบเฉพาะหน้าที่ของตนเอง ทำให้โค้ดอ่านง่าย ดูแลรักษาง่าย และสามารถขยายระบบในอนาคตได้

| Layer | หน้าที่ |
|--------|----------|
| **Router** | รับ HTTP Request, เรียกใช้งาน Service และส่ง HTTP Response กลับ |
| **Service** | จัดการ Business Logic และควบคุมลำดับการทำงานของระบบ |
| **Repository** | ติดต่อฐานข้อมูลและจัดการการอ่าน/เขียนข้อมูล |
| **Schema** | ตรวจสอบ (Validation) และกำหนดรูปแบบข้อมูล Request/Response ด้วย Pydantic |
| **Model** | กำหนดโครงสร้างตารางฐานข้อมูลด้วย SQLAlchemy ORM |
| **Utils** | ฟังก์ชันช่วยเหลือที่สามารถนำกลับมาใช้ซ้ำได้ เช่น Password Hashing และ JWT |
| **Core** | ส่วนกลางของระบบ เช่น Config, Enum, Exception, Regex และ Validators |

> การแบ่ง Layer ในลักษณะนี้ช่วยให้แต่ละส่วนของระบบมีหน้าที่ชัดเจน ลดการพึ่งพากันระหว่างโมดูล (Low Coupling) และเพิ่มความสามารถในการดูแลรักษา ทดสอบ และขยายระบบในอนาคต
