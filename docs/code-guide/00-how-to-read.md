# Code Guide 00: วิธีอ่านโค้ด CareFlow

## จุดประสงค์

คู่มือนี้จัดทำเพื่อช่วยให้ผู้ที่ไม่เคยเขียนโค้ดสามารถทำความเข้าใจโครงสร้างและการทำงานของ CareFlow และใช้ทบทวนก่อนอธิบายโครงงาน

## 1. อย่าเริ่มจากการจำทุกบรรทัด

ให้เริ่มจากคำถามว่า

1. ผู้ใช้ทำอะไร
2. Application ส่งข้อมูลไปที่ไหน
3. Backend รับข้อมูลที่ไหน
4. ส่วนใดประมวลผล
5. ข้อมูลถูกเก็บที่ไหน
6. ผลลัพธ์กลับไปแสดงที่ใด

## 2. Flow พื้นฐาน

```text
ผู้ใช้
 ↓
Mobile / Web
 ↓
API Request
 ↓
Router
 ↓
Service
 ↓
Repository / Model
 ↓
Database
 ↓
Response
 ↓
Mobile / Web
```

## 3. คำศัพท์พื้นฐาน

- Client: โปรแกรมที่ผู้ใช้ใช้งาน เช่น Mobile หรือ Web
- Backend: ส่วนประมวลผลของระบบ
- API: ช่องทางสื่อสารระหว่าง Client กับ Backend
- Request: ข้อมูลที่ Client ส่งไป
- Response: ข้อมูลที่ Backend ส่งกลับ
- Database: แหล่งจัดเก็บข้อมูล
- Router: จุดรับ API Request
- Service: ส่วนประมวลผล Business Logic
- Repository: ส่วนจัดการการเข้าถึงข้อมูล
- Model: โครงสร้างข้อมูลสำหรับ Database
- Schema: รูปแบบข้อมูล Request/Response

## 4. วิธีอ่านไฟล์

เมื่อเปิดไฟล์หนึ่งไฟล์ ให้ตอบให้ได้ก่อนว่า

> ไฟล์นี้มีหน้าที่อะไร?

จากนั้นดูว่า

> ใครเรียกไฟล์นี้?

และ

> ไฟล์นี้เรียกส่วนใดต่อ?

## 5. วิธีเตรียมตอบอาจารย์

ควรอธิบายจากภาพรวมก่อน แล้วจึงลงรายละเอียด เช่น

> Mobile ส่ง Request ไป Backend → Router รับ Request → Service ประมวลผล → Database จัดเก็บข้อมูล → Backend ส่ง Response กลับ Mobile

จากนั้นจึงค่อยชี้ว่าแต่ละขั้นอยู่ในไฟล์ใด

## 6. หลักสำคัญ

ไม่จำเป็นต้องจำ Code ทุกบรรทัด แต่ต้องเข้าใจว่า

- โค้ดส่วนนี้ทำอะไร
- ทำไมต้องมีส่วนนี้
- ข้อมูลไหลไปทางไหน
- ถ้าแก้ส่วนนี้จะกระทบส่วนใด
